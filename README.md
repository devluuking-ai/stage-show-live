# စတိတ်ရှိုး · Stage Show Live

TikTok LIVE အတွက် နီယွန် စတိတ်ရှိုး။ ကြည့်သူက comment ရေးလိုက်တာနဲ့ ပရိသတ်ထဲ ဝင်လာပြီး အတူကြည့်တယ်။ Gift ပို့ရင် နာမည်ကို မြန်မာအသံ (MC) နဲ့ ခေါ်ပေးတယ်။ အဆိုတော် (မိန်းကလေး / ယောက်ျား / စုံတွဲ) က သီချင်းအချိန်အလိုက် အမူအရာ ပြောင်းပြီး ဆိုတယ်။ နောက်ခံသီချင်း၊ စင်မီးအလင်း၊ အလိုအလျောက် ကြေညာချက်တွေ ပါပါတယ်။

မူရင်း code: Kent Juno ၏ Chánh Điện Online (MIT license) ကို စတိတ်ရှိုး ပုံစံ ပြောင်းထားတာ ဖြစ်ပါတယ်။

| Folder | ဘာလဲ |
|---|---|
| `index.html`, `assets/` | ဝက်ဘ်ဆိုက် static version — လူတိုင်း ကိုယ်တိုင် ဝင်ကြည့်လို့ရတဲ့ စာမျက်နှာ (Cloudflare Pages တင်လို့ရ) |
| `live/` | LIVE tool အစုံ: Node server, overlay 9:16, control panel |

## ဖုန်းမှာ (Termux) ထည့်သွင်းနည်း — GitHub ကနေ

Node.js 20+ နဲ့ git လိုပါတယ်။

```bash
pkg install git nodejs
git clone https://github.com/devluuking-ai/stage-show-live.git
cd stage-show-live/live
npm install
npm start
```

**Update လုပ်နည်း** (version အသစ် ထွက်ရင် zip ပြန် down စရာ မလိုပါ):

```bash
cd ~/stage-show-live
git pull
cd live
npm start
```

**TikTok ချိတ်ဆက်မှု — API key မလိုတော့ပါ (v26):** အရင်က သုံးတဲ့ Euler Stream လက်မှတ် service က အခမဲ့ key နဲ့ လက်မှတ် မထုတ်ပေးတော့လို့၊ လက်မှတ်ကို **ကိုယ်တိုင် ထုတ်တဲ့ open-source စနစ် (ttl-live)** နဲ့ အစားထိုးထားတယ် — TikTok ရဲ့ ကိုယ်ပိုင် webmssdk ကို ဖုန်းထဲမှာပဲ run ပြီး လက်မှတ် ထုတ်တာမို့ အကောင့်/key/plan ဘာမှ မလိုပါ၊ အမြဲတမ်း အခမဲ့ပါ။ လိုအပ်ချက်: **Node 22+** (Termux မှာ `pkg upgrade nodejs`)။

**Control ကို နောက် device ကနေ သုံးနည်း (v27):** LIVE လွှင့်တဲ့ ဖုန်းမှာ overlay ပဲ အပြည့် ဖွင့်ထားပြီး၊ control ကို နောက် ဖုန်း/ကွန်ပျူတာ ကနေ သီးခြား သုံးနိုင်တယ်။ Device နှစ်ခုလုံး **Wi-Fi အတူတူ** ချိတ်ထားရမယ်။ Server စတင်လိုက်ရင် Termux log မှာ `📱 နောက် device (Wi-Fi တူရမယ်) ကနေ Control: http://192.168.x.x:3000/live/control.html` ဆိုပြီး လိပ်စာ ပြပေးတယ် — အဲဒီ လိပ်စာကို နောက် device ရဲ့ Chrome မှာ ဖွင့်ရုံပဲ။ သတိ: Wi-Fi တူတူသုံးနေတဲ့ သူတိုင်း control ကို ဖွင့်နိုင်တာမို့ ကိုယ့် အိမ် Wi-Fi လို စိတ်ချရတဲ့ network မှာပဲ သုံးပါ (အင်တာနက် အပြင်ကနေ ဝင်လို့ မရပါ)။

1. Chrome မှာ `http://localhost:3000/live/control.html` ဖွင့်ပါ (control panel)။
2. Control ကနေ overlay ကို ဖွင့်ပြီး **အသံဖွင့်ရန်** ကို တစ်ခါ နှိပ်ပါ (browser က အသံ auto-play ပိတ်ထားလို့)။
3. TikTok မှာ **Mobile gaming / screen share LIVE** ဖွင့်ပါ — ပုံမှန် camera LIVE ဆို overlay မပါပါ။
4. LIVE ပွင့်ပြီးမှ control မှာ `@username` ရိုက်ပြီး **ချိတ်ဆက်မယ်** နှိပ်ပါ။

LIVE မဖွင့်သေးဘဲ စမ်းချင်ရင်: control ထဲက **အပြန်အလှန် စမ်းသပ်ရန်**, **လူအတု 15/36/64/100** နဲ့ **Bot** တွေနဲ့ စမ်းလို့ရတယ်။

## ပါဝင်တဲ့ အင်္ဂါရပ်များ

- **အဆိုတော်**: မိန်းကလေး / ယောက်ျား / စုံတွဲ (နှစ်ယောက်) — control မှာ ရွေးလို့ရတယ်။ အမူအရာက သီချင်း အချိန်အလိုက် အလိုအလျောက် ပြောင်းတယ်: သီချင်း မစခင် မိုက်ချပြီး ရပ်နေ → အစပိုင်း မိုက် တစ်လက်ကိုင် → အလယ်ပိုင်း မိုက် နှစ်လက်ကိုင် → အဆုံးသတ် လက်ဝှေ့ယမ်း။ စုံတွဲ ဆိုရင် တစ်လှည့်စီ ဆိုပြီး၊ အတူဆိုတဲ့ အပိုင်းမှာ နှစ်ယောက်လုံး နှစ်လက်ကိုင်၊ အဆုံးမှာ နှစ်ယောက်လုံး လက်ဝှေ့ယမ်းတယ်။ နှစ်ယောက်လုံး စင်ပေါ်က နီယွန်အဝိုင်း အတွင်းထဲမှာ ရပ်တယ်။
- **ပရိသတ်**: နီယွန် ယောက်ျား / မိန်းကလေး avatar တွေ — အပြာရောင် ကြမ်းပြင်ပေါ်မှာ အရွယ်အစား အတူတူ ရပ်ကြည့်တယ်။ လက်မြှောက် / လက်ချ အမူအရာ ကိုယ့်စည်းချက်နဲ့ကိုယ် ပြောင်းတယ်၊ ဘေးတိုက်/ရှေ့နောက် ဖြည်းဖြည်းချင်း ရွေ့လျားနေတယ်၊ ခြေရင်းမှာ အရိပ် ပါတယ်။
- **ဆုချ အခန်း**: သရဖူ (အကြီးဆုံး) gift ပို့ရင် ပို့တဲ့သူက လှေကားက တက်ပြီး အဆိုတော် ဘေးမှာ ဆု ပေးတယ် — ဆု ပြပြီး အလိုအလျောက် ပျောက်တယ်၊ ပြီးရင် အောက်ဆင်း၊ ကိုယ့်နေရာ ပြန်သွားပြီး အားပေးတယ်။
- **Gift effect**: နီယွန် မီးပွား (ပန်းရောင်/ရွှေရောင် ကြယ်ပွင့်) နဲ့ ပန်းပွင့်လေးတွေ — code နဲ့ ဆွဲတာတွေ ဖြစ်လို့ ပုံဖိုင် မလိုပါ။
- **Gift အမျိုးအစားများ**: TikTok gift catalog အပြည့် (Rose 1 coin ကနေ TikTok Universe 44,999 coin အထိ 19 မျိုး + သရဖူ/ပန်းစည်း) — တကယ့် LIVE gift တွေကို နာမည်နဲ့ မှတ်မိပြီး မြန်မာ နာမည် + emoji နဲ့ ပြတယ်။ Gift ပေးရင် ပေးတဲ့သူရဲ့ ခေါင်းပေါ်မှာ gift အမျိုးအစား (ဥပမာ "🦁 ခြင်္သေ့") ကို ရွှေရောင် tag နဲ့ 3 စက္ကန့် ပြတယ်။ Control မှာ gift ခလုတ် 21 ခု (အမျိုးအစား အစုံ) + အရေအတွက် ရွေးစရာ ပါတယ်။
- **ခေါင်းစဉ်**: ပွဲနာမည် ဘောင်က စာသားအရှည်အလိုက် ကွက်တိ ကျဉ်းချဲ့တယ်၊ "ကြိုဆိုပါတယ် · အားပေးကြပါ" စာက သီးသန့် pill ဘောင်နဲ့ ရှိတယ်။
- **Intro ကြေညာချက်**: စတိတ်ရှိုး စဖွင့်တာနဲ့ ကြိုဆို ကြေညာချက် အသံ (15 စက္ကန့်) အလိုအလျောက် ပွင့်တယ် — အဲဒီအချိန် နောက်ခံသီချင်း အသံ အလိုအလျောက် လျော့ပေးတယ်။ Control က **📣 Intro ဖွင့်** ခလုတ်နဲ့လည်း ကြိုက်တဲ့အချိန် ပြန်ဖွင့်လို့ရတယ်။ ဖိုင် အစားထိုးချင်ရင် `assets/intro.mp3` ကို အစားထိုးပါ။
- **သီချင်း**: built-in ၂ ပုဒ် + ကိုယ့်သီချင်း upload (control ကနေ MP3 တင်လို့ရ, အများဆုံး 25MB)။ Upload သီချင်းက **ယာယီပဲ** — မှတ်ဉာဏ်ထဲမှာပဲ ထားပြီး disk မှာ မသိမ်းပါ၊ server/Termux ပိတ်လိုက်ရင် ပျောက်သွားလို့ ပြန်ဖွင့်ရင် ပြန်တင်ရမယ်။ အသံ အတက်အကျ ညှိပေးတဲ့ compressor ပါလို့ upload သီချင်း အသံ မတိုးတော့ပါ။

## ကြည့်သူတွေ လုပ်လို့ရတာ

- **Comment တစ်ခုခု**: ပရိသတ်ထဲ ဝင်လာမယ် (အများဆုံး 100 ယောက်, 24 → 36 → 64 → 100 အလိုအလျောက် တိုးတယ်)။ ပြည့်ရင် အကြာဆုံး ငြိမ်နေတဲ့၊ gift မပို့ဖူးသူက နေရာ ဖယ်ပေးတယ်။
- **Keyword** `ယောက်ျား` (သို့) `မိန်းကလေး` လို့ ရေးရင် ကိုယ့် avatar ရုပ် ပြောင်းတယ်။
- **Gift ပို့**: နာမည် banner တက်တယ်၊ MC အသံနဲ့ ခေါ်ပေးတယ် (သူ့ comment နောက်ဆုံးစာကို အားပေးစကားအဖြစ် သုံးတယ်)၊ effect ထွက်ပြီး Top ပံ့ပိုးသူ စာရင်းမှာ အမှတ် တက်တယ်။ သရဖူ gift ဆို ဆုချ အခန်း ပွင့်တယ်။
- **Like နှိပ်**: အရုပ်ခေါင်းပေါ် အသဲလေးတွေ ပျံတယ်။

## Control panel မှာ လုပ်လို့ရတာ

- **စင် အပြင်အဆင်**: ပွဲနာမည်၊ အောက်စာ၊ အဆိုတော် (မိန်းကလေး/ယောက်ျား/စုံတွဲ)၊ အသံ (Nilar/Thiha)၊ နောက်ခံသီချင်း (၁/၂/ကိုယ့်သီချင်း)၊ ကိုယ့်သီချင်း MP3 upload။
- **အပြန်အလှန် စမ်းသပ်ရန်**: နာမည်နဲ့ comment/gift ပို့ပြီး စမ်းလို့ရတယ် — **Avatar ရုပ်** (အလိုအလျောက်/ယောက်ျား/မိန်းကလေး) ရွေးပြီး ထည့်လို့ရတယ်။ လူအတု ဖြည့်တာလည်း ဒီ ရွေးချယ်မှုနဲ့ သက်ရောက်တယ်။
- **Bot**: အရေအတွက်၊ အရှိန် အပြင် **Bot Avatar** (အလိုအလျောက်/ယောက်ျား/မိန်းကလေး) ရွေးလို့ရတယ် — bot ဖွင့်ထားတုန်း ပြောင်းရင်လည်း ချက်ချင်း သက်ရောက်တယ်။

## ပြင်ဆင်ချင်ရင်

- ပွဲနာမည်နဲ့ အောက်စာ: control panel → **စင် အပြင်အဆင်** မှာ ပြောင်းလို့ရတယ်။
- နောက်ခံသီချင်း: control ကနေ MP3 upload တင်တာ အလွယ်ဆုံးပဲ။ (သို့) `assets/music/music1.mp3` နဲ့ `music2.mp3` ကို ကိုယ့် MP3 နဲ့ အစားထိုးပါ။
- စင်နောက်ခံပုံ: `assets/hall.jpg` (1080×1920) ကို အစားထိုးပါ — ဒါပေမယ့် ပရိသတ် နေရာတွေက ဒီပုံရဲ့ ကြမ်းပြင်နဲ့ ချိန်ထားတာမို့ ပုံပြောင်းရင် နေရာတွေ လွဲနိုင်တယ်။
- အသံ: Nilar (မိန်းကလေး) / Thiha (ယောက်ျား) — control မှာ ရွေးလို့ရတယ်။ အဆိုတော် ပြောင်းရင် အသံလည်း လိုက်ပြောင်းတယ် (စုံတွဲ ဆိုရင် Nilar ပဲ ထားတယ်)။

## လုံခြုံရေး

- **TikTok အကောင့် မသုံးပါ။** Server က live အခန်းရဲ့ အများမြင် event တွေကိုပဲ username နဲ့ ဖတ်တယ်။ Password, cookie, session မလို၊ မသိမ်းပါ။
- **ကိုယ့်စက်ပေါ်မှာပဲ ပွင့်တယ်။** Server က `127.0.0.1` မှာပဲ နားထောင်တယ် — LAN / Internet က ဝင်မရပါ။
- **တခြား website တွေ ထိန်းချုပ်မရပါ။** WebSocket က ဒီ server ရဲ့ စာမျက်နှာတွေဆီကပဲ လက်ခံတယ် (Origin စစ်တယ်)၊ Host header က localhost ဖြစ်ရမယ်။
- **Static file whitelist:** `/assets` နဲ့ `/live` ပဲ ပေးတယ်။ `.env`, `node_modules`, server code, `package.json` တွေ အကုန် 404။
- နာမည်/comment/gift နာမည်တွေ အရှည် ကန့်သတ်ထားတယ်၊ settings က သတ်မှတ်ထားတဲ့ key နဲ့ အတိုင်းအတာအတွင်းပဲ လက်ခံတယ်၊ TTS စာသားကို XML escape လုပ်တယ်။
- TTS တန်းစီ အများဆုံး 15 ကြောင်း (spam ကာကွယ်ရန်)။

## မှတ်ချက်တွေ

- `tiktok-live-connector` က community library ပါ — TikTok တရားဝင် API မဟုတ်ပါ။ TikTok စနစ် ပြောင်းရင် ရပ်သွားနိုင်တယ်။
- အသံက Microsoft Edge Read Aloud ဝန်ဆောင်မှုကို Internet ကနေ သုံးတယ် (Nilar / Thiha)။ လွှင့်တဲ့စက်မှာ Internet လိုတယ်။
- `assets/` ထဲက ပုံတွေနဲ့ သီချင်းတွေကို ကိုယ့်အရင်းအမြစ်နဲ့ အစားထိုးလို့ရတယ်။
